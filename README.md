# HR-WORKFORCE-ANALYTICS
📊 HR Workforce Analytics Dashboard

An interactive HR Workforce Analytics dashboard built with Microsoft Power BI to analyze employee demographics, workforce performance, attendance, engagement, productivity, job satisfaction, and other key HR metrics.

This project demonstrates how HR data can be transformed into meaningful business insights through data visualization, KPI analysis, interactive filtering, and workforce analytics.

---

🎯 Project Objective

The objective of this project is to provide an interactive view of workforce data and help HR teams understand:

- Workforce composition
- Employee demographics
- Department-level performance
- Employee attendance
- Productivity trends
- Job satisfaction
- Employee engagement
- Peer feedback
- Work-life balance
- Salary and workforce metrics
- Performance patterns across different employee groups

---

🛠️ Tools & Technologies

- Power BI — Dashboard development and visualization
- Microsoft Excel — Data source and data preparation
- Power Query — Data cleaning and transformation
- DAX — Calculated measures and KPIs
- Data Visualization — Interactive charts, KPI cards, filters and slicers

---

📌 Dashboard Features

🔹 Interactive Filters

The dashboard includes interactive slicers for:

- Employee ID
- Attrition Risk
- Business Unit
- Department
- Education Level
- Performance Rating
- Work Location
- Gender
- Employment Type
- Job Title

These filters allow users to analyze specific employee segments and dynamically explore workforce patterns.

📊 Visualizations

1. Work-Life Balance Score

Analyzes work-life balance across different:

- Skill levels
- Marital statuses

This helps identify differences in employee work-life balance across workforce segments.

2. Attendance by Department

Compares attendance performance across departments to identify departments with higher or lower attendance levels.

3. Peer Feedback Score

Shows peer feedback scores across different performance categories, helping understand employee perception and performance relationships.

4. Productivity Score by Year

Displays the yearly trend of employee productivity and helps identify changes in workforce productivity over time.

5. Job Satisfaction Score

A gauge visual represents the overall job satisfaction score compared with the possible range.

6. Engagement Score by Business Unit

Compares engagement across business units and highlights the overall workforce engagement pattern.
